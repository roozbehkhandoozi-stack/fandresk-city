فندرسک سیتی — نسخه چندنفره

فایل‌ها:
- fandersk-city-online.html : بازی اصلاح‌شده
- server.js : سرور چندنفره WebSocket
- package.json : وابستگی سرور

اجرا روی کامپیوتر:
1) Node.js نصب باشد.
2) هر سه فایل را در یک پوشه بگذار.
3) در همان پوشه اجرا کن: npm install
4) بعد اجرا کن: npm start
5) بازی روی http://localhost:3000 باز می‌شود.

برای بازی با دوستان از اینترنت، همین پوشه را روی یک سرویس میزبانی Node.js قرار بده.
سرویس باید WebSocket را پشتیبانی کند و دستور شروع آن npm start باشد.
بعد همه با همان آدرس سایت وارد شوند و «ورود مهمان» را بزنند.

نکته: در این نسخه، چندنفره و چت از طریق سرور WebSocket کار می‌کند. ثبت‌نام/ذخیره آنلاین حساب‌ها هنوز به دیتابیس جداگانه نیاز دارد؛ حالت مهمان پیشرفت را روی همان دستگاه نگه می‌دارد.
